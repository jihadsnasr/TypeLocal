# TypeLocal

A simple typing speed test that runs right in your terminal. No internet, no account, no sign-up. Open it, type, and see how fast you are.

## What it does

TypeLocal shows you a sentence and you type it. The sentences are fun facts, like "Octopuses have three hearts and blue blood", so you learn something while you practice.

- **Live colors:** letters turn green when you type them right and red when you get them wrong. Letters you haven't typed yet stay gray, and a highlight shows where you are.
- **Fixing mistakes:** Backspace works, so you can correct yourself as you go.
- **Automatic timing:** the clock starts when you press your first key and stops when you finish the sentence.
- **Results after every round:**
  - Time taken
  - Characters typed
  - Correct characters
  - Accuracy (as a percentage)
  - WPM (words per minute)
  - Accurate WPM (your speed counting only the correct letters)

## How to use it

1. Download `TypeLocal.exe` from this page.
2. Double-click it to open.
3. Press **Enter** to start, then type the sentence you see.

Between rounds you can use:

| Key | What it does |
|-----|--------------|
| Enter | Next sentence |
| c | Change topic |
| q | Quit |

## What's a "WPM"?

It means words per minute. Typing tests count every 5 characters as one "word", so the score is fair no matter which sentence you get.

## Notes

- Works on Windows for now. 
- Everything runs on your computer. Nothing is sent anywhere.
